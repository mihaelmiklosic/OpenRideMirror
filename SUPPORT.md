# Support

This is an experimental open-source project, not a commercial bike computer and not an official Garmin or Waveshare product.

Before opening an issue:

1. follow [Build and use OpenRideMirror](GETTING_STARTED.md) and read [Troubleshooting](docs/troubleshooting.md);
2. run `./orm doctor`, `./orm protocol check` and `./orm test`;
3. identify the exact ESP32 board, display controller, Garmin product and SDK/core versions;
4. say whether the failure occurs in demo mode, BLE simulator mode or with Garmin;
5. include logs with private paths, GPS positions, keys and credentials removed.

Hardware port requests are most useful when accompanied by documentation, a maintained driver and real-device test results.
