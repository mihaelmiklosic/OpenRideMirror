After downloading

Connect the display and run this once from the OpenRideMirror folder:

./orm map flash

This one command installs the map, compiles the live firmware and flashes the connected ESP32.

The ZIP contains OrmMapData.h, OrmMapLabels.h, OrmGreenMask.h, a manifest and instructions. You never need to edit them.
