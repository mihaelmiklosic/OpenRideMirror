Overpass request and privacy

For a real area, your selected geographic bounds and requested feature types are sent directly from this page to a public Overpass API to retrieve OpenStreetMap data. No Garmin activity, device telemetry, account data or local files are sent. The map pack is assembled and downloaded in your browser. The built-in sample makes no network request.

Install the downloaded map

Leave the ZIP in your Downloads folder, connect the display, open Terminal in the OpenRideMirror repository, then run:

./orm map flash

The command finds the newest OpenRideMirror map pack in Downloads, installs it, compiles the live firmware and flashes the connected ESP32.
